# ERP Modules

Atlas ERP is composed of several business-domain modules. Each module provides specific functionality while seamlessly integrating with the others.

## Available Modules

- [HR (Human Resources)](hr.md) — Manage employees, attendance, leaves, and payroll.
- [Finance & Accounting](finance.md) — Manage invoices, payments, and the general ledger.
- [Projects](projects.md) — Manage project tasks, milestones, and time tracking.
- [Employee Self-Service (ESS)](ess.md) — Empower employees to manage their own attendance, leaves, and helpdesk tickets.
- [Platform Admin](platform-admin.md) — Global control center for tenant management and system configuration.
